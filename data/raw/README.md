## Safety notice

`PhiUSIIL_Phishing_URL_Dataset.csv` contains real phishing URL strings. They are untrusted, inert text. Never click, open, resolve, request, crawl, preview, ping, or otherwise contact a URL or hostname from this file. Do not display raw URL values in reports or user-facing messages.
